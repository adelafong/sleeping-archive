QUICK PREVIEW
Double-click index.html on your computer. The website itself will open locally.
Some browsers restrict inline PDF viewing from local files; this does not affect a normally hosted version.

FREE PUBLISHING WITH GITHUB PAGES
1. Sign in to GitHub.
2. Create a new PUBLIC repository, for example: sleeping-archive
3. Upload everything inside this folder, keeping the assets folder intact.
4. Open the repository: Settings > Pages.
5. Under Build and deployment, choose: Deploy from a branch.
6. Branch: main / (root), then Save.
7. Wait for GitHub to show the live site URL.

IMPORTANT
Keep the website URL stable. Once your QR code points to it, you can replace research-book.pdf later without changing the QR code, as long as the site URL stays the same.
